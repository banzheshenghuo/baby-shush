# 婴儿嘘嘘哄睡

给新手爸妈的「嘘嘘（Shush）」哄睡小工具：打开即播放柔和的「嘘」声白噪音，中间是缓慢的呼吸律动圆圈，轻触圆圈即可播放 / 暂停。支持锁屏、息屏后台持续播放，可安装到手机主屏幕当 App 用。

## 声音方案

主音源为随仓库分发的真实「嘘」声录音 `audio/xuxu.mp3`（约 2 分 47 秒，循环播放），由 `<audio>` 元件播放——因此可以享受系统媒体通道：**锁屏 / 息屏 / 后台继续播放**，锁屏界面显示封面与播放控件。录音已纳入 Service Worker 预缓存，离线同样可用。

若录音文件异常加载失败，页面自动回退到程序化合成的「嘘」声（固定种子：棕噪声 + 低频起伏 + 首尾 1 秒等功率交叉淡化的 12 秒无缝循环），保证任何情况下都有一段柔和音源可播。

## 使用

- 浏览器打开 <https://banzheshenghuo.github.io/baby-shush/>，进入页面即自动开始播放
- **轻触中间的呼吸圆圈**：播放 ⇄ 暂停（呼吸律动随播放状态同步启停）
- **本次计时**：播放时走表、暂停时停表；关闭或强杀应用后，本次时长自动归档进历史，下次进入从零重新计时
- **定时停止**：点「定时」选 15 / 30 / 60 分钟或不定时；主界面实时显示「MM:SS 后停止」秒级倒计时（暂停播放时倒计时照常走），到点自动暂停；选「不定时」可随时取消
- **历史记录**：底部「历史记录」可查看每次哄睡的日期与时长（不足 1 分钟不记录；含总次数 / 累计时长），支持一键清空
- 音量完全由设备音量键控制；锁屏 / 耳机线控 / 车载控件同样可控
- 「添加到主屏幕」后即为全屏 PWA，支持离线打开

## 平台说明（如实）

- **Android（Chrome/Edge 等）**：锁屏、息屏持续播放，锁屏显示控件 ✓
- **iOS（Safari / 主屏 PWA）**：播放中的 HTMLAudioElement 在锁屏后通常可持续；但 iOS 不允许网页自动出声，**每次打开需轻触屏幕一次（任意位置）**即可开始。这是平台限制，所有网页应用相同
- 桌面浏览器：一切功能可用；被浏览器自动播放策略拦截时，轻触屏幕任意位置即可

## 功能清单

- 打开即播：进入页面即尝试自动播放（HTML 预加载音频 + `autoplay` 双保险）；被策略拦截时轻触屏幕任意位置即可开始
- 呼吸律动圆圈，点按切换播放 / 暂停
- 本次播放计时 + 历史记录（localStorage，仅记录满 1 分钟的会话，最多保留 100 条）
- 定时停止：15 / 30 / 60 分钟预设档位，秒级倒计时展示，到点自动暂停
- 锁屏 / 息屏 / 后台播放（Media Session API），息屏期间计时照常累计
- 音量由设备硬件控制，页面零音量逻辑
- PWA：可安装、离线可用（Service Worker 网络优先 + 缓存回退；音频文件缓存优先，再次进入即刻起播）
- 尊重系统「减弱动态效果」设置
- 零依赖、零构建，音源本地自带（真实录音 + 合成兜底，无任何外链）
